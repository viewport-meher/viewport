# ViewPort 🖥️📱

**Live device preview for HTML, CSS and JS — see your webpage in real device frames instantly.**

ViewPort is a VS Code extension that lets you preview your HTML files in real device frames — just like Flutter's Device Preview, but for web developers.

---

## ✨ Features

- 📱 **29+ Device Frames** — Android, iPhone, iPad, MacBook, Desktop
- ⚡ **Live Reload** — Save your file, preview updates instantly
- 🌐 **Works Offline** — 100% local, zero tracking, completely private
- 🎨 **Auto Scale** — Device frames auto-fit your screen size
- 🖱️ **Right Click Support** — Right click any HTML file → Open with ViewPort

---

## 🚀 How to Use

1. Open any HTML file in VS Code
2. Click **`Go ViewPort`** in the bottom status bar
3. Your browser opens with live device preview
4. Select any device from the sidebar
5. Edit and save your file — preview updates automatically!

## 🔒 Privacy First

ViewPort runs entirely on your local machine. No data is sent anywhere. No internet required.
